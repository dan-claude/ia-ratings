When recreating, Claude should read this file fully before writing any code,

============================
GOAL
============================
Build a web application that:
0) Stores each film's Internet Archive description in the database and
   displays it above the embed player.
1) Pulls all films in the Internet Archive collection
   "2026-public-domain-day-film-contest"
2) Allows authenticated users to rate films across multiple criteria
3) Supports an admin/judge mode with CSV export
4) Lets users log in with their archive.org account (AUTH_SCHEME=ia, default)
   or with local email/password accounts (AUTH_SCHEME=local); optionally also
   "Continue with GitHub" (OAuth web flow) when GITHUB_CLIENT_ID and
   GITHUB_CLIENT_SECRET are set (see docs/GITHUB_LOGIN.md)
5) Gives admins an in-app panel: sync, criteria management, user admin
   promotion, DB browser, JSON backup/restore
6) Deploys to Railway via a multi-stage Dockerfile and GitHub Actions

============================
TECH STACK
============================
- Client: React + Vite (single-file App.jsx, no external UI libraries)
- Server: Flask with Blueprints
- Database: SQLite (WAL mode, 5s busy_timeout)
- Auth: Flask session-based (cookie). AUTH_SCHEME=ia proxies login to
  archive.org xauthn; AUTH_SCHEME=local uses werkzeug password hashing.
  Optional GitHub OAuth (no scopes; keyed on the numeric GitHub id) works with either.
- Rate limiting: Flask-Limiter on /api/auth/login and /api/auth/register
- IA sync: requests for search, aiohttp for concurrent description fetches
- Python: 3.12
- Relative imports: all server modules EXCEPT app.py use relative imports (e.g. from ..db import Database)
- app.py uses ABSOLUTE imports (e.g. from server.config import load_settings) because it is the entry point

DATABASE SCHEMA (AUTHORITATIVE)
============================

Table: schema_migrations
  version    INTEGER PRIMARY KEY
  applied_at TEXT NOT NULL DEFAULT (datetime('now'))

Table: users
  id            INTEGER PRIMARY KEY AUTOINCREMENT
  email         TEXT NOT NULL UNIQUE
  password_hash TEXT NOT NULL
  is_admin      INTEGER NOT NULL DEFAULT 0
  created_at    TEXT NOT NULL DEFAULT (datetime('now'))
  ia_username   TEXT           <- added by migration v4; NULL for local users
  github_id     TEXT           <- added by migration v5; NULL unless created via GitHub
  github_username TEXT         <- added by migration v5; display only, refreshed on login

Table: app_settings   <- added by migration v6
  key        TEXT PRIMARY KEY      (e.g. 'collection' = the active archive.org collection)
  value      TEXT NOT NULL
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))

Table: films
  id            INTEGER PRIMARY KEY AUTOINCREMENT
  ia_identifier TEXT NOT NULL UNIQUE
  title         TEXT
  description   TEXT           <- normalized plain-text description
  collection    TEXT NOT NULL
  mediatype     TEXT
  metadata_json TEXT           <- NULL in current upsert implementation
  updated_at    TEXT NOT NULL DEFAULT (datetime('now'))

Table: criteria
  id         INTEGER PRIMARY KEY AUTOINCREMENT
  key        TEXT NOT NULL UNIQUE
  label      TEXT NOT NULL
  min_score  INTEGER NOT NULL DEFAULT 1
  max_score  INTEGER NOT NULL DEFAULT 5
  sort_order INTEGER NOT NULL
  active     INTEGER NOT NULL DEFAULT 1

Table: ratings
  id         INTEGER PRIMARY KEY AUTOINCREMENT
  user_id    INTEGER NOT NULL
  film_id    INTEGER NOT NULL
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
  UNIQUE(user_id, film_id)
  FOREIGN KEY(user_id) REFERENCES users(id)
  FOREIGN KEY(film_id) REFERENCES films(id)

Table: rating_scores
  rating_id   INTEGER NOT NULL
  criteria_id INTEGER NOT NULL
  score       INTEGER NOT NULL
  PRIMARY KEY (rating_id, criteria_id)
  FOREIGN KEY(rating_id) REFERENCES ratings(id)
  FOREIGN KEY(criteria_id) REFERENCES criteria(id)

Indexes:
  idx_ratings_user     ON ratings(user_id)
  idx_films_collection ON films(collection)
  idx_users_ia_username ON users(ia_username) WHERE ia_username IS NOT NULL  (UNIQUE, v4)
  idx_users_github_id ON users(github_id) WHERE github_id IS NOT NULL  (UNIQUE, v5)

MIGRATIONS (run at startup in db.py):
  v1: ALTER TABLE users ADD COLUMN is_admin INTEGER NOT NULL DEFAULT 0
  v2: ALTER TABLE ratings ADD COLUMN updated_at TEXT NOT NULL DEFAULT (datetime('now'))
  v3: ALTER TABLE films ADD COLUMN description TEXT
  v4: ALTER TABLE users ADD COLUMN ia_username TEXT
      + CREATE UNIQUE INDEX idx_users_ia_username ... WHERE ia_username IS NOT NULL

  v5: ALTER TABLE users ADD COLUMN github_id TEXT; ADD COLUMN github_username TEXT

(Full request/response detail: API_CLIENT_SERVER.md)

  POST   /api/auth/login     ia mode:    { username, password } -> { ok: true }
                             local mode: { email, password }    -> { ok: true }
  GET    /api/auth/github/login     -> 302 to GitHub (state stored in session); 404 if not configured
  GET    /api/auth/github/callback  -> 302 "/" on success (new session), else 302 "/?auth_error=<code>"
                             code: github_state | github_denied | github_failed
  POST   /api/auth/logout    -> { ok: true }

User:
  GET    /api/me             -> { id, email, created_at, is_admin }

Criteria: (requires auth, defined in routes/user.py NOT films.py)
  GET    /api/criteria       -> [{ key, label, min, max, sortOrder, active }]
  IMPORTANT: field names are "min" and "max" (NOT "min_score"/"max_score")

Films: (requires auth)
  GET    /api/films/next     -> { identifier, title, description, embedUrl }
                                or 404 { error, code: "no_films" }  (no films at all: DB never synced / emptied)
                                or 404 { error, code: "all_rated" } (films exist; user rated them all)
  GET    /api/films/<id>     -> { identifier, title, description, embedUrl }
                                or 404 { error: "Film not found" }

Ratings: (requires auth)
  POST   /api/films/<id>/ratings
         Payload: { "scores": { "<key>": number } }
         ALL active criteria MUST be present (validates completeness)
         Response: { ok: true }

Admin: (requires is_admin=1 session)
  POST   /api/admin/sync     -> 202 { ok: true, status }  (starts a BACKGROUND sync; 409 if already running)
  GET    /api/admin/sync/status -> { state: idle|running|done|error, phase: listing|descriptions|null,
                                     done, total, synced, error, started_at, finished_at, film_count }
  GET    /api/admin/settings -> { collection, default_collection, collections:[{name,films}] }
  PUT    /api/admin/settings/collection { collection } -> { ok, collection, default_collection, collections, film_count }
                             validated slug (letters/digits/./_/-, <=100 chars); 400 invalid; 409 while a job runs.
                             The ACTIVE collection decides which films raters see and where sync/import put films.
  POST   /api/admin/import/preview { csv_text } -> { headers, row_count, sample_rows, suggested_mapping, collection }
  POST   /api/admin/import { csv_text, mapping:{link,title,description,extra[]} (0-based column indexes),
                             dry_run?, on_existing: "skip"|"update" (required unless dry_run), lookup_titles? }
                             dry_run -> { summary:{rows,new,existing,skipped}, skipped:[{row,reason}], samples }
                             real    -> { result:{added,updated,skipped_existing,skipped_invalid,title_lookup_started}, summary, skipped }
                             ONLY archive.org item links (archive.org/details|embed|download/<id>) are imported;
                             400 bad file/mapping/on_existing/no importable rows; 409 while a background job runs
                             (status endpoint also reports kind: sync|titles and a "titles" phase)
  POST   /api/admin/db/empty { confirm: "EMPTY" } -> { ok, deleted: { rating_scores, ratings, films } }
                             deletes all films + ratings (keeps users/criteria); 400 w/o confirm; 409 during a sync
  GET    /api/admin/ratings.csv -> CSV download
  GET    /api/admin/criteria -> all criteria incl. inactive (raw column names)
  POST   /api/admin/criteria { key, label, min_score, max_score, sort_order, active } -> 201
  PUT    /api/admin/criteria/<id> (partial; key immutable)
  POST   /api/admin/users/<id>/make-admin   -> { ok, user_id, is_admin: true }
  POST   /api/admin/users/<id>/revoke-admin -> { ok, user_id, is_admin: false }
  GET    /api/admin/db/tables  -> { table: rowCount }
  GET    /api/admin/db/schema  -> { table: createSql }
  GET    /api/admin/db/<table>?order_by=&limit=&offset=
         order_by must match ^col( ASC| DESC)?$; films adds rating_count;
         users omits password_hash
  GET    /api/admin/db/backup  -> JSON attachment
         { app:"ia_ratings", format_version:1, schema_version, exported_at, tables }
  POST   /api/admin/db/restore (body = backup JSON; destructive, one transaction)

Health:
  GET    /api/health         -> { ok: true }

API film object shape:
{
  "identifier": "<ia_identifier>",
  "title": "<title>",
  "description": "<plain text or null>",   <- CAN BE NULL
  "embedUrl": "https://archive.org/embed/<identifier>"
}

Error response shape: { "error": "<message>" }
  Note: key is "error", NOT "ok: false"

Auth error codes:
  register ValueError  -> 400
  register duplicate   -> 409 (KeyError)
  login ValueError     -> 400
  login bad creds      -> 401 (PermissionError; also "Could not reach archive.org")
  not logged in        -> 401
  not admin            -> 403

import os
from dataclasses import dataclass, field

_DEV_SECRET = "dev-secret-change-me"
_DEFAULT_DB_PATH = os.path.join(os.path.dirname(__file__), "app.db")


def _env(name: str, default: str):
    """Field default that reads the env var each time Settings() is created.

    (A plain `= os.environ.get(...)` default is evaluated once, at import time,
    so later env changes such as per-test DB_PATH values would be ignored.)
    """
    return field(default_factory=lambda: os.environ.get(name, default))


@dataclass(frozen=True)
class Settings:
    # DEFAULT Internet Archive collection, used until an admin sets one in the admin
    # panel (stored in the database: app_settings 'collection'). Films are only shown
    # to raters (and synced / imported) for the active collection.
    collection: str = "2026-public-domain-day-film-contest"
    db_path: str = _env("DB_PATH", _DEFAULT_DB_PATH)
    session_secret: str = _env("SESSION_SECRET", _DEV_SECRET)
    # "ia"    — delegate login to archive.org (default)
    # "local" — local email/password accounts
    auth_scheme: str = _env("AUTH_SCHEME", "ia")
    # Optional "Continue with GitHub" login, offered alongside the scheme above.
    # Enabled only when both the client id and secret are set.
    github_client_id: str = _env("GITHUB_CLIENT_ID", "")
    github_client_secret: str = _env("GITHUB_CLIENT_SECRET", "")
    # Normally leave empty: GitHub then uses the callback URL registered on the
    # OAuth app. Set it only if you registered more than one callback URL.
    github_redirect_uri: str = _env("GITHUB_REDIRECT_URI", "")

    @property
    def github_enabled(self) -> bool:
        return bool(self.github_client_id and self.github_client_secret)

    @property
    def oauth_providers(self) -> list[str]:
        """Names of the OAuth providers the login screen should offer."""
        return ["github"] if self.github_enabled else []


def load_settings() -> Settings:
    return Settings()

import sqlite3
from typing import Any, Iterable, Optional

class Database:
    def __init__(self, path: str):
        self.path = path
        self._init_schema()

    def connect(self) -> sqlite3.Connection:
        # NOTE: each call returns a fresh connection.
        # SQLite itself is ACID-capable, but application-level atomicity requires
        # grouping related writes in a single transaction on a single connection.
        conn = sqlite3.connect(self.path)
        conn.row_factory = sqlite3.Row
        # Enforce referential integrity.
        conn.execute("PRAGMA foreign_keys = ON;")

        # Concurrency + durability tuning suitable for a small web app.
        # - WAL improves read/write concurrency.
        # - synchronous=NORMAL is a common durability/performance trade-off.
        #   If you need maximum durability, use FULL.
        # - busy_timeout avoids immediate 'database is locked' errors under load.
        conn.execute("PRAGMA journal_mode = WAL;")
        conn.execute("PRAGMA synchronous = NORMAL;")
        conn.execute("PRAGMA busy_timeout = 5000;")
        return conn

    def _init_schema(self) -> None:
        conn = self.connect()
        try:
            # Base schema (idempotent).
            conn.executescript("""
            CREATE TABLE IF NOT EXISTS schema_migrations (
              version INTEGER PRIMARY KEY,
              applied_at TEXT NOT NULL DEFAULT (datetime('now'))
            );

            CREATE TABLE IF NOT EXISTS users (
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              email TEXT NOT NULL UNIQUE,
              password_hash TEXT NOT NULL,
              is_admin INTEGER NOT NULL DEFAULT 0,
              created_at TEXT NOT NULL DEFAULT (datetime('now'))
            );

            CREATE TABLE IF NOT EXISTS films (
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              ia_identifier TEXT NOT NULL UNIQUE,
              title TEXT,
              description TEXT,
              collection TEXT NOT NULL,
              mediatype TEXT,
              metadata_json TEXT,
              updated_at TEXT NOT NULL DEFAULT (datetime('now'))
            );

            CREATE TABLE IF NOT EXISTS criteria (
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              key TEXT NOT NULL UNIQUE,
              label TEXT NOT NULL,
              min_score INTEGER NOT NULL DEFAULT 1,
              max_score INTEGER NOT NULL DEFAULT 5,
              sort_order INTEGER NOT NULL,
              active INTEGER NOT NULL DEFAULT 1
            );

            CREATE TABLE IF NOT EXISTS ratings (
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              user_id INTEGER NOT NULL,
              film_id INTEGER NOT NULL,
              created_at TEXT NOT NULL DEFAULT (datetime('now')),
              updated_at TEXT NOT NULL DEFAULT (datetime('now')),
              UNIQUE(user_id, film_id),
              FOREIGN KEY(user_id) REFERENCES users(id),
              FOREIGN KEY(film_id) REFERENCES films(id)
            );

            CREATE TABLE IF NOT EXISTS rating_scores (
              rating_id INTEGER NOT NULL,
              criteria_id INTEGER NOT NULL,
              score INTEGER NOT NULL,
              PRIMARY KEY (rating_id, criteria_id),
              FOREIGN KEY(rating_id) REFERENCES ratings(id),
              FOREIGN KEY(criteria_id) REFERENCES criteria(id)
            );

            CREATE INDEX IF NOT EXISTS idx_ratings_user ON ratings(user_id);
            CREATE INDEX IF NOT EXISTS idx_films_collection ON films(collection);
            """)

            # ---- MIGRATIONS ----
            # v1: Add users.is_admin for older databases.
            cols = {r["name"] for r in conn.execute("PRAGMA table_info(users)").fetchall()}
            if "is_admin" not in cols:
                conn.execute("ALTER TABLE users ADD COLUMN is_admin INTEGER NOT NULL DEFAULT 0;")
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (1);")

            

            # v2: Add ratings.updated_at for older databases.
            rcols = {r["name"] for r in conn.execute("PRAGMA table_info(ratings)").fetchall()}
            if "updated_at" not in rcols:
                conn.execute("ALTER TABLE ratings ADD COLUMN updated_at TEXT NOT NULL DEFAULT (datetime('now'));")
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (2);")
            
            # v3: Add films.description for older databases.
            fcols = {r["name"] for r in conn.execute("PRAGMA table_info(films)").fetchall()}
            if "description" not in fcols:
                conn.execute("ALTER TABLE films ADD COLUMN description TEXT;")
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (3);")

            # v4: Add users.ia_username for Internet Archive SSO.
            ucols = {r["name"] for r in conn.execute("PRAGMA table_info(users)").fetchall()}
            if "ia_username" not in ucols:
                conn.execute("ALTER TABLE users ADD COLUMN ia_username TEXT;")
                conn.execute("CREATE UNIQUE INDEX IF NOT EXISTS idx_users_ia_username ON users(ia_username) WHERE ia_username IS NOT NULL;")
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (4);")

            # v5: Add users.github_id / users.github_username for GitHub OAuth login.
            # github_id (GitHub's numeric account id) is the stable key; the
            # username can change on GitHub, so it is stored only for display.
            ucols = {r["name"] for r in conn.execute("PRAGMA table_info(users)").fetchall()}
            if "github_id" not in ucols:
                conn.execute("ALTER TABLE users ADD COLUMN github_id TEXT;")
                conn.execute("ALTER TABLE users ADD COLUMN github_username TEXT;")
                conn.execute("CREATE UNIQUE INDEX IF NOT EXISTS idx_users_github_id ON users(github_id) WHERE github_id IS NOT NULL;")
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (5);")

            # v6: app_settings key/value table (e.g. the active film collection,
            # which admins change from the admin panel).
            tables = {r["name"] for r in conn.execute("SELECT name FROM sqlite_master WHERE type='table'").fetchall()}
            if "app_settings" not in tables:
                conn.execute("""
                  CREATE TABLE app_settings (
                    key TEXT PRIMARY KEY,
                    value TEXT NOT NULL,
                    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
                  )
                """)
                conn.execute("INSERT OR IGNORE INTO schema_migrations (version) VALUES (6);")

# ---- SEED DATA ----
            conn.execute("""
              INSERT OR IGNORE INTO criteria (key, label, sort_order) VALUES
                ('originality', 'Originality', 1),
                ('use_of_archive_materials', 'Use of Archive Materials', 2)
            """)
            conn.commit()
        finally:
            conn.close()


    def fetchone(self, sql: str, params: Iterable[Any] = ()) -> Optional[sqlite3.Row]:
        conn = self.connect()
        try:
            return conn.execute(sql, tuple(params)).fetchone()
        finally:
            conn.close()

    def fetchall(self, sql: str, params: Iterable[Any] = ()) -> list[sqlite3.Row]:
        conn = self.connect()
        try:
            return conn.execute(sql, tuple(params)).fetchall()
        finally:
            conn.close()

import sqlite3
from typing import Optional

from ..db import Database


class UserRepository:
    def __init__(self, db: Database):
        self.db = db

    def create_user(self, email: str, password_hash: str) -> int:
        conn = self.db.connect()
        try:
            cur = conn.execute(
                "INSERT INTO users (email, password_hash) VALUES (?, ?)",
                (email, password_hash),
            )
            conn.commit()
            return int(cur.lastrowid)
        finally:
            conn.close()

    def get_by_email(self, email: str) -> Optional[sqlite3.Row]:
        return self.db.fetchone(
            "SELECT id, email, password_hash, is_admin, created_at FROM users WHERE email = ?",
            (email,),
        )

    def get_by_id(self, user_id: int) -> Optional[sqlite3.Row]:
        return self.db.fetchone(
            "SELECT id, email, is_admin, created_at FROM users WHERE id = ?",
            (user_id,),
        )

    def get_by_ia_username(self, ia_username: str) -> Optional[sqlite3.Row]:
        return self.db.fetchone(
            "SELECT id, email, is_admin, created_at FROM users WHERE ia_username = ?",
            (ia_username,),
        )

    def create_ia_user(self, ia_username: str) -> int:
        conn = self.db.connect()
        try:
            cur = conn.execute(
                "INSERT INTO users (email, password_hash, ia_username) VALUES (?, 'IA_AUTH', ?)",
                (f"{ia_username}@users.archive.org", ia_username),
            )
            conn.commit()
            return int(cur.lastrowid)
        finally:
            conn.close()

    def get_by_github_id(self, github_id: str) -> Optional[sqlite3.Row]:
        return self.db.fetchone(
            "SELECT id, email, is_admin, created_at, github_username FROM users WHERE github_id = ?",
            (github_id,),
        )

    def create_github_user(self, github_id: str, github_username: str) -> int:
        # The email column is NOT NULL UNIQUE, so synthesise one from the stable
        # numeric id (GitHub's own noreply format) — it never collides, even if
        # the username later changes hands.
        conn = self.db.connect()
        try:
            cur = conn.execute(
                "INSERT INTO users (email, password_hash, github_id, github_username) "
                "VALUES (?, 'GITHUB_AUTH', ?, ?)",
                (f"{github_id}+{github_username}@users.noreply.github.com", github_id, github_username),
            )
            conn.commit()
            return int(cur.lastrowid)
        finally:
            conn.close()

    def set_github_username(self, user_id: int, github_username: str) -> None:
        conn = self.db.connect()
        try:
            conn.execute(
                "UPDATE users SET github_username = ? WHERE id = ?",
                (github_username, int(user_id)),
            )
            conn.commit()
        finally:
            conn.close()

    def set_admin(self, user_id: int, is_admin: bool) -> None:
        conn = self.db.connect()
        try:
            conn.execute(
                "UPDATE users SET is_admin = ? WHERE id = ?",
                (1 if is_admin else 0, int(user_id)),
            )
            conn.commit()
        finally:
            conn.close()

import re
from typing import Optional

from ..db import Database

# Internet Archive collection identifiers: letters, digits, '.', '_' and '-'.
COLLECTION_RE = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$")


class AppSettingsRepository:
    """Key/value settings that admins change at runtime (table `app_settings`)."""

import json
import sqlite3
from typing import Optional
from ..db import Database

class FilmRepository:
    @staticmethod
    def _html_to_text(s: str) -> str:
        """Convert IA HTML description to plain text preserving line structure."""
        import re
        # Block-level and list tags → newline
        s = re.sub(r'<br\s*/?>', '\n', s, flags=re.IGNORECASE)
        s = re.sub(r'</div>', '\n', s, flags=re.IGNORECASE)
        s = re.sub(r'<div[^>]*>', '', s, flags=re.IGNORECASE)
        s = re.sub(r'<li[^>]*>', '\n', s, flags=re.IGNORECASE)
        s = re.sub(r'</li>', '', s, flags=re.IGNORECASE)
        s = re.sub(r'</?ul[^>]*>', '\n', s, flags=re.IGNORECASE)
        s = re.sub(r'</?ol[^>]*>', '\n', s, flags=re.IGNORECASE)
        s = re.sub(r'</?p[^>]*>', '\n', s, flags=re.IGNORECASE)
        # Strip all remaining tags (keep text content, e.g. URLs inside <a>)
        s = re.sub(r'<[^>]+>', '', s)
        # Decode common HTML entities
        entities = [('&amp;', '&'), ('&lt;', '<'), ('&gt;', '>'),
                    ('&quot;', '"'), ('&#39;', "'"), ('&nbsp;', ' ')]
        for ent, char in entities:
            s = s.replace(ent, char)
        # Replace residual non-breaking spaces with regular spaces
        s = s.replace('\xa0', ' ')
        # Lines that are now only whitespace become empty (blank lines)
        s = '\n'.join(line if line.strip() else '' for line in s.split('\n'))
        # Collapse 3+ newlines to a single blank line
        s = re.sub(r'\n{3,}', '\n\n', s)
        return s.strip()

    @staticmethod
    def _looks_like_html(s: str) -> bool:
        import re
        return bool(re.search(r'<(br|div|p|b|i|a|span)\b', s, flags=re.IGNORECASE))

    def _clean_plain_text(self, s: str) -> str:
        """Clean plain-text descriptions that use \xa0 as line-break surrogates."""
        import re
        # \xa0 \xa0 (two or more nbsp) = paragraph break
        s = re.sub(r'[ \xa0]*\xa0[ \xa0]*\xa0[ \xa0]*', '\n\n', s)
        # single \xa0 = line break
        s = re.sub(r'[ ]*\xa0[ ]*', '\n', s)
        s = re.sub(r'\n{3,}', '\n\n', s)
        return s.strip()

    def _normalize_description(self, v):
        # IA may return description as str or list; store a single text blob.
        if v is None:
            return None
        if isinstance(v, list):
            parts = [str(x) for x in v if x is not None and str(x).strip()]
            if not parts:
                return None
            joined = "\n\n".join(parts)
            v = joined
        s = str(v).strip()
        if not s:
            return None
        if self._looks_like_html(s):
            return self._html_to_text(s)
        return self._clean_plain_text(s)

    def __init__(self, db: Database, collection):
        """collection: a slug, or a zero-arg callable returning the *current* slug
        (the admin can change it at runtime)."""
        self.db = db
        self._collection = collection

        return c() if callable(c) else c

    def existing_identifiers(self, identifiers: list[str]) -> set[str]:
        """Subset of identifiers that already have a row in films (any collection)."""
        found: set[str] = set()
        ids = list(identifiers)
        conn = self.db.connect()
        try:
            for i in range(0, len(ids), 500):  # stay under SQLite's bound-variable limit
                chunk = ids[i:i + 500]
                q = ",".join("?" * len(chunk))
                rows = conn.execute(
                    f"SELECT ia_identifier FROM films WHERE ia_identifier IN ({q})", chunk
                ).fetchall()
                found.update(r["ia_identifier"] for r in rows)
        finally:
            conn.close()
        return found

    def import_rows(self, rows: list[dict], on_existing: str) -> dict:
        """Insert (or update) films from a spreadsheet import in one transaction.

        Each row: {identifier, title|None, description|None, metadata|None}.
        on_existing: "skip" leaves films that already exist untouched; "update"
        overwrites the fields the row provides (a missing title/description/metadata
        never blanks out what is stored). New films get title = identifier when the
        row has no title, and always join this app's collection.
        Returns {"added", "updated", "skipped_existing"}.
        """
        if on_existing not in ("skip", "update"):
            raise ValueError('on_existing must be "skip" or "update"')
        counts = {"added": 0, "updated": 0, "skipped_existing": 0}
        existing = self.existing_identifiers([r["identifier"] for r in rows])
        conn = self.db.connect()
        try:
            with conn:
                for r in rows:
                    ident = r["identifier"]
                    meta = json.dumps(r["metadata"], ensure_ascii=False) if r.get("metadata") else None
                    if ident in existing:
                        if on_existing == "skip":
                            counts["skipped_existing"] += 1
                            continue
                        conn.execute(
                            """
                            UPDATE films SET
                              title = COALESCE(?, title),
                              description = COALESCE(?, description),
                              metadata_json = COALESCE(?, metadata_json),
                              collection = ?,
                              updated_at = datetime('now')
                            WHERE ia_identifier = ?
                            """,
                            (r.get("title"), r.get("description"), meta, self.collection, ident),
                        )
                        counts["updated"] += 1
                    else:
                        conn.execute(
                            """
                            INSERT INTO films (ia_identifier, title, description, collection, mediatype, metadata_json, updated_at)
                            VALUES (?, ?, ?, ?, 'movies', ?, datetime('now'))
                            """,
                            (ident, r.get("title") or ident, r.get("description"), self.collection, meta),
                        )
                        counts["added"] += 1
        finally:
            conn.close()
        return counts

    def update_titles(self, titles: dict[str, str]) -> int:
        """Set looked-up titles, but only where the stored title is blank or just the identifier."""
        n = 0
        conn = self.db.connect()
        try:
            with conn:
                for ident, title in titles.items():
                    n += conn.execute(
                        "UPDATE films SET title = ?, updated_at = datetime('now') "
                        "WHERE ia_identifier = ? AND (title IS NULL OR title = '' OR title = ia_identifier)",
                        (title, ident),
                    ).rowcount
        finally:
            conn.close()
        return n

    def get_identifiers_without_description(self, identifiers: list[str]) -> set[str]:
        """Return the subset of identifiers that have no description stored yet.

        Films that aren't in the database at all count as "without": on a first
        sync (e.g. after emptying the database) every film needs its full
        description fetched.
        """
        if not identifiers:
            return set()
        conn = self.db.connect()
        try:
            placeholders = ",".join("?" * len(identifiers))
            rows = conn.execute(
                f"SELECT ia_identifier FROM films WHERE ia_identifier IN ({placeholders})"
                f" AND description IS NOT NULL AND description != ''",
                identifiers,
            ).fetchall()
            return set(identifiers) - {r["ia_identifier"] for r in rows}
        finally:
            conn.close()

import sqlite3
from ..db import Database

class RatingRepository:
    def __init__(self, db: Database):
        self.db = db

    def upsert_rating(self, user_id: int, film_id: int) -> int:
        """Create or update a rating row and return its id.

        Note: This method commits within its own transaction. For application-
        level atomicity when also writing scores, prefer upsert_rating_with_scores().
        """
        conn = self.db.connect()
        try:
            self._upsert_rating_row(conn, user_id, film_id)
            row = conn.execute(
                "SELECT id FROM ratings WHERE user_id=? AND film_id=?",
                (user_id, film_id),
            ).fetchone()
            conn.commit()
            return int(row["id"])
        finally:
            conn.close()

    def upsert_scores_bulk(self, rating_id: int, scores: list[tuple[int,int]]) -> None:
        """Upsert a set of criterion scores for a rating.

        Note: This method commits within its own transaction. For application-
        level atomicity when also creating/updating the rating row, prefer
        upsert_rating_with_scores().
        """
        conn = self.db.connect()
        try:
            self._upsert_scores_bulk(conn, rating_id, scores)
            conn.commit()
        finally:
            conn.close()

    def upsert_rating_with_scores(
        self,
        user_id: int,
        film_id: int,
        scores: list[tuple[int,int]],
    ) -> int:
        """Atomically upsert a rating and all of its scores in one transaction.

        This is the primary method the service layer should use. It guarantees
        that the rating row and its per-criterion scores are written together.

        Returns:
            rating_id: the id of the rating row.
        """
        conn = self.db.connect()
        try:
            # IMMEDIATE: acquire a write lock up front to reduce mid-transaction lock errors.
            conn.execute("BEGIN IMMEDIATE")
            self._upsert_rating_row(conn, user_id, film_id)
            row = conn.execute(
                "SELECT id FROM ratings WHERE user_id=? AND film_id=?",
                (user_id, film_id),
            ).fetchone()
            rating_id = int(row["id"])
            self._upsert_scores_bulk(conn, rating_id, scores)
            conn.commit()
            return rating_id
        except Exception:
            conn.rollback()
            raise
        finally:
            conn.close()

    def _upsert_rating_row(self, conn: sqlite3.Connection, user_id: int, film_id: int) -> None:
        """Internal: upsert rating row using an existing connection."""
        conn.execute(
                """
                INSERT INTO ratings (user_id, film_id, updated_at)
                VALUES (?, ?, datetime('now'))
                ON CONFLICT(user_id, film_id) DO UPDATE SET updated_at=datetime('now')
                """,
                (user_id, film_id),
            )

    def _upsert_scores_bulk(self, conn: sqlite3.Connection, rating_id: int, scores: list[tuple[int,int]]) -> None:
        """Internal: upsert score rows using an existing connection."""
        for criteria_id, score in scores:
            conn.execute(
                    """
                    INSERT INTO rating_scores (rating_id, criteria_id, score)
                    VALUES (?, ?, ?)
                    ON CONFLICT(rating_id, criteria_id) DO UPDATE SET score=excluded.score
                    """,
                    (rating_id, criteria_id, score),
                )

    def list_active_criteria_for_export(self) -> list[sqlite3.Row]:
        conn = self.db.connect()
        try:
            return conn.execute(
                "SELECT id, key, sort_order FROM criteria WHERE active=1 ORDER BY sort_order"
            ).fetchall()
        finally:
            conn.close()

    def list_ratings_for_export(self, collection: str) -> list[sqlite3.Row]:
        conn = self.db.connect()
        try:
            return conn.execute(
                """
                SELECT r.id as rating_id, r.created_at, u.email as user_email,
                       f.ia_identifier as identifier, f.title as title
                FROM ratings r
                JOIN users u ON u.id = r.user_id
                JOIN films f ON f.id = r.film_id
                WHERE f.collection=?
                ORDER BY r.created_at DESC
                """,
                (collection,),
            ).fetchall()
        finally:
            conn.close()

    def get_score(self, rating_id: int, criteria_id: int) -> int | None:
        row = self.db.fetchone(

    def count_ratings_for_film(self, film_id: int) -> int:

    def avg_score_for_film_criterion(self, film_id: int, criteria_id: int) -> float | None:

import sqlite3
import requests as _requests
from werkzeug.security import generate_password_hash, check_password_hash
from ..models.user import User
from ..repositories.user_repo import UserRepository

class AuthService:
    def __init__(self, users: UserRepository):
        self.users = users

    def register(self, email: str, password: str) -> int:
        email = email.strip().lower()
        if not email or not password:
            raise ValueError("email and password required")
        ph = generate_password_hash(password)
        try:
            return self.users.create_user(email, ph)
        except sqlite3.IntegrityError as e:
            raise KeyError("Email already registered") from e

    def login(self, email: str, password: str) -> int:
        email = email.strip().lower()
        if not email or not password:
            raise ValueError("email and password required")
        row = self.users.get_by_email(email)
        if not row or not check_password_hash(row["password_hash"], password):
            raise PermissionError("Invalid credentials")
        return int(row["id"])

    def login_via_ia(self, username: str, password: str) -> int:
        username = username.strip()
        if not username or not password:
            raise ValueError("username and password required")
        try:
            resp = _requests.post(
                "https://archive.org/services/xauthn/?op=login",
                json={"email": username, "password": password},
                timeout=10,
            )
            data = resp.json()
        except _requests.exceptions.RequestException as exc:
            raise PermissionError("Could not reach archive.org") from exc
        except Exception:
            data = {}
        if not data.get("success"):
            reason = (data.get("values") or {}).get("reason") or "Invalid archive.org credentials"
            raise PermissionError(reason)
        row = self.users.get_by_ia_username(username)
        if row:
            return int(row["id"])
        return self.users.create_ia_user(username)

    def get_me(self, user_id: int) -> User:
        row = self.users.get_by_id(user_id)
        if not row:
            raise LookupError("User not found")
        return User(id=int(row["id"]), email=str(row["email"]), created_at=str(row["created_at"]), is_admin=("is_admin" in row.keys() and bool(row["is_admin"])))

"""GitHub OAuth (web application flow) login.

Flow: the browser is sent to GitHub's authorize page with a random `state`;
GitHub redirects back with `?code&state`; we exchange the code for an access
token, read the account's public profile, and find-or-create the local user
keyed on GitHub's numeric account id.

No OAuth scopes are requested: the public profile (id + login) is all we need,
so the app never sees the user's email address or any private data.
"""
import sqlite3
from urllib.parse import urlencode

import requests as _requests

from ..repositories.user_repo import UserRepository

AUTHORIZE_URL = "https://github.com/login/oauth/authorize"
TOKEN_URL = "https://github.com/login/oauth/access_token"
USER_URL = "https://api.github.com/user"
_TIMEOUT = 10


class GitHubAuthError(Exception):
    """The GitHub exchange failed; the message is safe to log, not to show."""


class GitHubAuthService:
    def __init__(self, users: UserRepository, client_id: str, client_secret: str, redirect_uri: str = ""):
        self.users = users
        self.client_id = client_id
        self.client_secret = client_secret
        self.redirect_uri = redirect_uri

    def authorize_url(self, state: str) -> str:
        params = {"client_id": self.client_id, "state": state}
        if self.redirect_uri:
            params["redirect_uri"] = self.redirect_uri
        return f"{AUTHORIZE_URL}?{urlencode(params)}"

    def login_with_code(self, code: str) -> int:
        """Complete the flow for an authorization `code`; return the local user id."""
        if not code:
            raise GitHubAuthError("missing code")
        token = self._exchange_code(code)
        github_id, login = self._fetch_profile(token)

        row = self.users.get_by_github_id(github_id)
        if row:
            if row["github_username"] != login:
                self.users.set_github_username(int(row["id"]), login)
            return int(row["id"])
        try:
            return self.users.create_github_user(github_id, login)
        except sqlite3.IntegrityError:
            # A concurrent callback for the same account created it first.
            row = self.users.get_by_github_id(github_id)
            if row:
                return int(row["id"])
            raise

    def _exchange_code(self, code: str) -> str:
        payload = {
            "client_id": self.client_id,
            "client_secret": self.client_secret,
            "code": code,
        }
        if self.redirect_uri:
            payload["redirect_uri"] = self.redirect_uri
        try:
            resp = _requests.post(
                TOKEN_URL, data=payload, headers={"Accept": "application/json"}, timeout=_TIMEOUT
            )
            data = resp.json()
        except (_requests.exceptions.RequestException, ValueError) as exc:
            raise GitHubAuthError("token exchange request failed") from exc
        token = data.get("access_token") if isinstance(data, dict) else None
        if not token:
            err = data.get("error") if isinstance(data, dict) else None
            raise GitHubAuthError(f"token exchange rejected: {err or 'no access_token'}")
        return token

    def _fetch_profile(self, token: str) -> tuple[str, str]:
        try:
            resp = _requests.get(
                USER_URL,
                headers={
                    "Authorization": f"Bearer {token}",
                    "Accept": "application/vnd.github+json",
                },
                timeout=_TIMEOUT,
            )
            data = resp.json()
        except (_requests.exceptions.RequestException, ValueError) as exc:
            raise GitHubAuthError("profile request failed") from exc
        if resp.status_code != 200 or not isinstance(data, dict) or not data.get("id") or not data.get("login"):
            raise GitHubAuthError(f"profile lookup failed: HTTP {resp.status_code}")
        return str(data["id"]), str(data["login"])

"""Runs long admin jobs (the Internet Archive sync, CSV-import title lookups)
in a background thread, one at a time.

A job can take minutes, so the admin API starts it and returns immediately;
the client polls `status()` to show progress. State lives in this process
only, which is fine because production runs a single gunicorn worker (see
CLAUDE.md) — it resets on restart.
"""
import logging
import threading
import time
from typing import Callable, Optional

logger = logging.getLogger(__name__)


def _now() -> float:
    return time.time()


class SyncService:
    def __init__(self, ia, films):
        self.ia = ia
        self.films = films
        self._lock = threading.Lock()
        self._thread: Optional[threading.Thread] = None
        self._status = self._blank_status()

    @staticmethod
    def _blank_status() -> dict:
        return {
            "state": "idle",        # idle | running | done | error
            "kind": None,           # sync | titles — which job this status is about
            "phase": None,          # listing | descriptions | titles (while running)
            "done": 0,
            "total": None,
            "synced": None,         # items processed by the last finished job (films synced / titles found)
            "error": None,
            "started_at": None,     # unix seconds
            "finished_at": None,
        }

    def status(self) -> dict:
        with self._lock:
            return dict(self._status)

    def is_running(self) -> bool:
        with self._lock:
            return self._status["state"] == "running"

    def start(self) -> bool:
        """Start an Internet Archive collection sync. False if a job is already running."""
        return self.start_job(
            "sync",
            lambda progress: self.ia.sync_collection(self.films, progress=progress),
            first_phase="listing",
        )

    def start_job(
        self,
        kind: str,
        fn: Callable[[Callable[[str, int, Optional[int]], None]], int],
        first_phase: Optional[str] = None,
    ) -> bool:
        """Run fn(progress) in the background; fn returns the number of items processed.

        Returns False (and does nothing) if another job is already running.
        """
        with self._lock:
            if self._status["state"] == "running":
                return False
            self._status = self._blank_status()
            self._status.update(state="running", kind=kind, phase=first_phase or kind, started_at=_now())
            self._thread = threading.Thread(target=self._run, args=(fn,), name=f"job-{kind}", daemon=True)
            self._thread.start()
            return True

    def wait(self, timeout: Optional[float] = None) -> None:
        """Block until the current sync finishes (used by tests)."""
        t = self._thread
        if t is not None:
            t.join(timeout)

    # -- internals ---------------------------------------------------------

    def _progress(self, phase: str, done: int, total: Optional[int]) -> None:
        with self._lock:
            self._status.update(phase=phase, done=done, total=total)

    def _run(self, fn) -> None:
        try:
            synced = fn(self._progress)
        except Exception as exc:  # noqa: BLE001 — surface any failure to the admin UI
            logger.exception("job.failed")
            with self._lock:
                self._status.update(
                    state="error", phase=None, error=str(exc) or exc.__class__.__name__, finished_at=_now()
                )
            return
        with self._lock:
            self._status.update(state="done", phase=None, synced=synced, finished_at=_now())

"""Populate the film database from a spreadsheet exported as CSV.

The admin picks which spreadsheet column holds what (see `mapping` below). Only
rows whose link points at an archive.org item are imported: the film is played
from archive.org, so a YouTube link, a bare title or free text is skipped (and
reported) rather than creating a film that can't be shown.

mapping = {
    "link":        <column index>,          # required: an archive.org item URL
    "title":       <column index> | None,   # optional; blank -> looked up / identifier
    "description": <column index> | None,   # optional
    "extra":       [<column index>, ...],   # optional: kept in films.metadata_json (admin-only)
}
Columns are addressed by index (not header text) so duplicate/blank headers work.
"""
import csv
import io
import re
from typing import Optional
from urllib.parse import urlsplit

MAX_BYTES = 2 * 1024 * 1024
MAX_ROWS = 5000

_ID_RE = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]{0,200}$")
_ARCHIVE_HOSTS = {"archive.org", "www.archive.org"}
_ITEM_PATHS = {"details", "embed", "download"}


def parse_archive_url(value: Optional[str]) -> Optional[str]:
    """Return the item identifier from an archive.org item URL, else None.

    Accepts https://archive.org/details/<id> (also /embed/<id>, /download/<id>,
    http, www, no scheme, trailing path/query). The host must be exactly
    archive.org / www.archive.org; anything else (YouTube, lookalike domains,
    bare identifiers, free text) returns None.
    """
    v = (value or "").strip()
    if not v or any(c.isspace() for c in v):
        return None
    if "://" not in v:
        v = "https://" + v
    try:
        u = urlsplit(v)
    except ValueError:
        return None
    if u.scheme not in ("http", "https") or (u.hostname or "").lower() not in _ARCHIVE_HOSTS:
        return None
    parts = [p for p in u.path.split("/") if p]
    if len(parts) < 2 or parts[0] not in _ITEM_PATHS:
        return None
    return parts[1] if _ID_RE.match(parts[1]) else None


def parse_csv(text: str) -> tuple[list[str], list[tuple[int, list[str]]]]:
    """Parse CSV text into (headers, [(row_number, cells)]).

    row_number is the spreadsheet row (header = 1), so messages match what the
    admin sees. Fully blank rows are dropped; short rows are padded.
    """
    if len(text.encode("utf-8")) > MAX_BYTES:
        raise ValueError(f"File is too large (maximum {MAX_BYTES // (1024 * 1024)} MB)")
    text = text.lstrip("﻿")
    try:
        records = list(csv.reader(io.StringIO(text, newline="")))
    except csv.Error as exc:
        raise ValueError(f"Could not read the CSV: {exc}") from exc
    numbered = [(i + 1, r) for i, r in enumerate(records) if any(c.strip() for c in r)]
    if not numbered:
        raise ValueError("The file is empty")
    _, header_cells = numbered[0]
    headers = [h.strip() for h in header_cells]
    width = len(headers)
    rows = [(n, (cells + [""] * width)[: max(width, len(cells))]) for n, cells in numbered[1:]]
    if not rows:
        raise ValueError("The file has a header row but no data rows")
    if len(rows) > MAX_ROWS:
        raise ValueError(f"Too many rows (maximum {MAX_ROWS})")
    return headers, rows


def suggest_mapping(headers: list[str], rows: list[tuple[int, list[str]]]) -> dict:
    """Guess a mapping: the link column is the one whose cells most often are archive.org links."""
    best, best_n = None, 0
    for i in range(len(headers)):
        n = sum(1 for _, cells in rows if i < len(cells) and parse_archive_url(cells[i]))
        if n > best_n:
            best, best_n = i, n

    def find(pattern: str, skip: Optional[int]) -> Optional[int]:
        rx = re.compile(pattern, re.IGNORECASE)
        for i, h in enumerate(headers):
            if i != skip and rx.search(h):
                return i
        return None

    return {
        "link": best,
        "title": find(r"\btitle\b", best),
        "description": find(r"description|statement|synopsis|summary", best),
        "extra": [],
    }


def validate_mapping(mapping, ncols: int) -> dict:
    """Return a cleaned mapping or raise ValueError with a message for the admin."""
    if not isinstance(mapping, dict):
        raise ValueError("mapping is required")

    def col(name: str, required: bool = False) -> Optional[int]:
        v = mapping.get(name)
        if v is None or v == "":
            if required:
                raise ValueError(f"Choose which column holds the {name}")
            return None
        if isinstance(v, bool) or not isinstance(v, int) or not 0 <= v < ncols:
            raise ValueError(f"Invalid column for {name}")
        return v

    extra = mapping.get("extra") or []
    if not isinstance(extra, list) or any(isinstance(x, bool) or not isinstance(x, int) or not 0 <= x < ncols for x in extra):
        raise ValueError("Invalid extra columns")
    return {
        "link": col("link", required=True),
        "title": col("title"),
        "description": col("description"),
        "extra": list(dict.fromkeys(extra)),
    }


class ImportService:
    def __init__(self, films, ia, sync):
        self.films = films
        self.ia = ia
        self.sync = sync

    # -- planning -----------------------------------------------------------

    def build_plan(self, headers, rows, mapping) -> list[dict]:
        """Classify every row: importable (new/existing) or skipped with a reason."""
        def cell(cells, idx):
            return cells[idx].strip() if idx is not None and idx < len(cells) else ""

        items, first_row_for = [], {}
        for rownum, cells in rows:
            link = cell(cells, mapping["link"])
            ident = parse_archive_url(link)
            item = {"row": rownum, "identifier": ident, "skip": None}
            if not link:
                item["skip"] = "No link"
            elif not ident:
                item["skip"] = "Not an archive.org item link"
            elif ident in first_row_for:
                item["skip"] = f"Duplicate of row {first_row_for[ident]}"
            if item["skip"]:
                items.append(item)
                continue
            first_row_for[ident] = rownum
            item["title"] = cell(cells, mapping["title"]) or None
            item["description"] = (
                self.films._normalize_description(cell(cells, mapping["description"])) or None
            )
            extras = {headers[i] or f"column {i + 1}": cells[i].strip()
                      for i in mapping["extra"] if i < len(cells) and cells[i].strip()}
            item["metadata"] = {"source": "csv_import", "columns": extras} if mapping["extra"] else None
            items.append(item)

        existing = self.films.existing_identifiers([i["identifier"] for i in items if not i["skip"]])
        for i in items:
            i["exists"] = (not i["skip"]) and i["identifier"] in existing
        return items

    @staticmethod
    def summarize(items: list[dict]) -> dict:
        ok = [i for i in items if not i["skip"]]
        return {
            "rows": len(items),
            "new": sum(1 for i in ok if not i["exists"]),
            "existing": sum(1 for i in ok if i["exists"]),
            "skipped": len(items) - len(ok),
        }

    @staticmethod
    def skipped_rows(items: list[dict], limit: int = 100) -> list[dict]:
        return [{"row": i["row"], "reason": i["skip"]} for i in items if i["skip"]][:limit]

    @staticmethod
    def samples(items: list[dict], limit: int = 5) -> list[dict]:
        out = []
        for i in items:
            if i["skip"]:
                continue
            desc = i["description"] or ""
            out.append({
                "row": i["row"],
                "identifier": i["identifier"],
                "title": i["title"],            # None -> will be looked up / identifier
                "description": desc[:200] + ("…" if len(desc) > 200 else ""),
                "exists": i["exists"],
            })
            if len(out) >= limit:
                break
        return out

    # -- doing it -----------------------------------------------------------

    def run(self, items: list[dict], on_existing: str, lookup_titles: bool) -> dict:
        ok = [i for i in items if not i["skip"]]
        counts = self.films.import_rows(ok, on_existing)
        lookup_started = False
        if lookup_titles:
            # Rows that gave no title; update_titles never overwrites a real title.
            ids = [i["identifier"] for i in ok
                   if not i["title"] and not (i["exists"] and on_existing == "skip")]
            if ids:
                lookup_started = self.sync.start_job("titles", lambda progress: self._lookup_titles(ids, progress))
        return {**counts, "skipped_invalid": len(items) - len(ok), "title_lookup_started": lookup_started}

    def _lookup_titles(self, identifiers: list[str], progress) -> int:
        titles = self.ia.fetch_titles(identifiers, progress=progress)
        return self.films.update_titles(titles)

import asyncio
import logging
import requests
from typing import Callable, Iterator, Optional

logger = logging.getLogger(__name__)


class InternetArchiveService:
    def __init__(self, collection):
        """collection: a slug, or a zero-arg callable returning the current slug."""
        self._collection = collection

    @property
    def collection(self) -> str:
        c = self._collection
        return c() if callable(c) else c

    def iter_collection_movies(self, rows: int = 100) -> Iterator[dict]:
        page = 1
        while True:
            payload = self._advancedsearch(page=page, rows=rows)
            docs = (payload.get("response") or {}).get("docs") or []
            if not docs:
                return
            for d in docs:
                yield d
            num_found = (payload.get("response") or {}).get("numFound") or 0
            if page * rows >= num_found or len(docs) < rows:
                return
            page += 1

    def sync_collection(
        self,
        films_repo,
        rows: int = 100,
        max_pages: Optional[int] = None,
        workers: int = 20,
        force: bool = False,
        progress: Optional[Callable[[str, int, Optional[int]], None]] = None,
    ) -> int:
        """Fetch movie docs from Internet Archive and upsert them into the films table.

        Uses asyncio + aiohttp for non-blocking concurrent description fetches.
        workers: max concurrent requests (semaphore limit).
        force: if True, re-fetch descriptions even for films already in DB.
        progress: optional callback(phase, done, total) for status reporting.
            phase "listing"      — reading the film list; total is None
            phase "descriptions" — fetching per-film descriptions; done/total films
        Returns number of films inserted/updated.
        """
        # Collect all docs first
        def report(phase: str, done: int, total: Optional[int]) -> None:
            if progress:
                progress(phase, done, total)

        all_docs: list[dict] = []
        report("listing", 0, None)
        for d in self.iter_collection_movies(rows=rows):
            all_docs.append(d)
            if len(all_docs) % rows == 0:
                report("listing", len(all_docs), None)
            if max_pages is not None and len(all_docs) >= max_pages * rows:
                break

        # Belt and braces: never count/upsert the same film twice.
        all_docs = list({d["identifier"]: d for d in all_docs if d.get("identifier")}.values())

        if not all_docs:
            return 0

        # Decide which films need a metadata fetch BEFORE upserting, so that
        # films with only a search-API description (plain, run-on) are still
        # treated as needing enrichment on first sync.
        identifiers = [d.get("identifier") for d in all_docs if d.get("identifier")]
        if force:
            need_desc = set(identifiers)
            print(f"  Force mode: re-fetching descriptions for all {len(need_desc)} films...")
        else:
            need_desc = films_repo.get_identifiers_without_description(identifiers)

        # Upsert with search-API data first so all films exist in DB
        films_repo.upsert_many_from_ia(all_docs)

        report("listing", len(all_docs), len(all_docs))
        if not need_desc:
            print(f"  All {len(identifiers)} films already have descriptions — skipping metadata fetch.")
            return len(all_docs)

        if not force:
            print(f"  Fetching descriptions for {len(need_desc)} new films "
                  f"({len(identifiers) - len(need_desc)} already cached)...")

        # Fetch concurrently with asyncio
        html_map = asyncio.run(self._fetch_all_descriptions(list(need_desc), workers, report))

        # Upsert again with enriched descriptions
        enriched = [
            dict(d, description=html_map[d["identifier"]], description_is_html=True)
            if d.get("identifier") in html_map else d
            for d in all_docs
        ]
        films_repo.upsert_many_from_ia(enriched)
        return len(all_docs)

    async def _fetch_all_descriptions(self, identifiers: list[str], workers: int, report=None) -> dict[str, str]:
        """Fetch HTML descriptions for all identifiers concurrently using aiohttp."""
        try:
            import aiohttp
        except ImportError:
            logger.warning("aiohttp not installed — falling back to threaded fetches. "
                           "Run: pip install aiohttp")
            return self._fetch_all_descriptions_threaded(identifiers, workers, report)

        sem = asyncio.Semaphore(workers)
        results: dict[str, str] = {}
        done = 0
        total = len(identifiers)

        async def fetch_one(session: aiohttp.ClientSession, ident: str) -> None:
            nonlocal done
            url = f"https://archive.org/metadata/{ident}/metadata/description"
            async with sem:
                try:
                    async with session.get(url, timeout=aiohttp.ClientTimeout(total=15)) as resp:
                        resp.raise_for_status()
                        data = await resp.json(content_type=None)
                        result = data.get("result")
                        if isinstance(result, str) and result.strip():
                            results[ident] = result
                except Exception as e:
                    logger.warning("fetch_description_html failed for %s: %s", ident, e)
                finally:
                    done += 1
                    if report:
                        report("descriptions", done, total)
                    if done % 10 == 0 or done == total:
                        print(f"  Descriptions: {done}/{total}", flush=True)

        connector = aiohttp.TCPConnector(limit=workers)
        async with aiohttp.ClientSession(connector=connector) as session:
            await asyncio.gather(*(fetch_one(session, ident) for ident in identifiers))

        return results

    def _fetch_all_descriptions_threaded(self, identifiers: list[str], workers: int, report=None) -> dict[str, str]:
        """Fallback threaded fetch if aiohttp is unavailable."""
        from concurrent.futures import ThreadPoolExecutor, as_completed
        html_map: dict[str, str] = {}
        done = 0
        with ThreadPoolExecutor(max_workers=workers) as executor:
            future_to_id = {
                executor.submit(self.fetch_description_html, ident): ident
                for ident in identifiers
            }
            for future in as_completed(future_to_id):
                ident = future_to_id[future]
                done += 1
                if report:
                    report("descriptions", done, len(identifiers))
                try:
                    result = future.result()
                    if result:
                        html_map[ident] = result
                    if done % 10 == 0 or done == len(identifiers):
                        print(f"  Descriptions: {done}/{len(identifiers)}", flush=True)
                except Exception as e:
                    logger.warning("fetch failed for %s: %s", ident, e)
        return html_map

    def fetch_title(self, identifier: str) -> Optional[str]:
        """Fetch an item's title from the metadata API. Returns None on failure/absence."""
        url = f"https://archive.org/metadata/{identifier}/metadata/title"
        try:
            r = requests.get(url, timeout=15)
            r.raise_for_status()
            result = r.json().get("result")
            if isinstance(result, list):
                result = result[0] if result else None
            if isinstance(result, str) and result.strip():
                return result.strip()
            return None
        except Exception as e:
            logger.warning("fetch_title failed for %s: %s", identifier, e)
            return None

    def fetch_titles(
        self,
        identifiers: list[str],
        workers: int = 10,
        progress: Optional[Callable[[str, int, Optional[int]], None]] = None,
    ) -> dict[str, str]:
        """Look up titles for many items concurrently. Items without a title are omitted."""
        from concurrent.futures import ThreadPoolExecutor, as_completed
        titles: dict[str, str] = {}
        total = len(identifiers)
        if progress:
            progress("titles", 0, total)
        with ThreadPoolExecutor(max_workers=workers) as executor:
            futures = {executor.submit(self.fetch_title, ident): ident for ident in identifiers}
            for done, future in enumerate(as_completed(futures), 1):
                title = future.result()
                if title:
                    titles[futures[future]] = title
                if progress:
                    progress("titles", done, total)
        return titles

    def fetch_description_html(self, identifier: str) -> Optional[str]:
        """Fetch the HTML description from the metadata API (sync). Returns None on failure."""
        url = f"https://archive.org/metadata/{identifier}/metadata/description"
        try:
            r = requests.get(url, timeout=15)
            r.raise_for_status()
            data = r.json()
            result = data.get("result")
            if isinstance(result, str) and result.strip():
                return result
            return None
        except Exception as e:
            logger.warning("fetch_description_html failed for %s: %s", identifier, e)
            return None

    def _advancedsearch(self, page: int, rows: int) -> dict:
        q = f"collection:{self.collection} AND mediatype:movies"
        url = "https://archive.org/advancedsearch.php"
        params = {
            "q": q,
            "fl[]": ["identifier", "title", "description"],
            "rows": rows,
            "page": page,
            # Without a stable sort, archive.org's paging returns overlapping
            # pages (duplicates), so a sync silently misses films.
            "sort[]": "identifier asc",
            "output": "json",
        }
        r = requests.get(url, params=params, timeout=30)
        r.raise_for_status()
        return r.json()

            raise LookupError("Film not found (sync first)")

            if c["key"] not in scores:
                raise ValueError(f"Missing score for: {c['key']}")

        for c in crit:
            try:
                n = int(scores[c["key"]])

                raise ValueError(f"Score for {c['key']} must be integer") from e
            if n < c["min_score"] or n > c["max_score"]:
                raise ValueError(f"Score for {c['key']} must be {c['min_score']}-{c['max_score']}")
            validated.append((int(c["id"]), n))

        # IMPORTANT: submit the rating and its scores in a single transaction.
        # This prevents partially-written ratings if the process crashes between steps.
        self.ratings.upsert_rating_with_scores(user_id, int(film_row["id"]), validated)

        import sqlite3, re
        if not key or not label:
            raise ValueError("key and label required")
        if not re.match(r"^[a-z0-9_]+$", key):
            raise ValueError("key must be lowercase letters/numbers/underscore")
        if min_score >= max_score:
            raise ValueError("invalid min/max")
        try:

        except sqlite3.IntegrityError as e:

        row = self.criteria.get_by_id(cid)
        if not row:
            raise LookupError("not found")

        new_label = label if label is not None else row["label"]
        new_min = int(min_score) if min_score is not None else int(row["min_score"])
        new_max = int(max_score) if max_score is not None else int(row["max_score"])
        new_so = int(sort_order) if sort_order is not None else int(row["sort_order"])
        new_active = int(active) if active is not None else int(row["active"])

        if new_min >= new_max:
            raise ValueError("invalid min/max")

        writer.writerow(["created_at", "user_email", "identifier", "title", *[c["key"] for c in crit]])

        for r in ratings:

            for c in crit:

                scores.append("" if s is None else s)

"""Logging configuration for the Flask server.

- Logs to stdout (good for local dev + containers)
- Timestamps, level, logger name
- Controlled via LOG_LEVEL (default INFO)
"""

from __future__ import annotations

import logging
import os
import sys


def configure_logging() -> None:
    """Configure Python logging for the server process."""
    level_name = os.getenv("LOG_LEVEL", "INFO").upper()
    level = getattr(logging, level_name, logging.INFO)

    root = logging.getLogger()
    if root.handlers:
        root.setLevel(level)
        return

    handler = logging.StreamHandler(sys.stdout)
    formatter = logging.Formatter(
        fmt="%(asctime)s %(levelname)s %(name)s: %(message)s",
        datefmt="%Y-%m-%dT%H:%M:%S%z",
    )
    handler.setFormatter(formatter)

    root.setLevel(level)
    root.addHandler(handler)
    logging.getLogger("werkzeug").setLevel(level)

@auth_bp.get("/api/auth/github/callback")
@limiter.limit("10 per minute; 50 per hour")
def github_callback():
    svc = _github_service()
    if svc is None:
        return jsonify({"error": "GitHub login is not configured"}), 404

    # The state is single-use: pop it so a captured callback URL can't be replayed.
    expected = session.pop("oauth_state", None)
    given = request.args.get("state", "")
    if not expected or not hmac.compare_digest(str(expected), given):
        return _login_error("github_state")

    if request.args.get("error"):  # e.g. the user clicked "Cancel" on GitHub
        return _login_error("github_denied")

    try:
        uid = svc.login_with_code(request.args.get("code", ""))
    except GitHubAuthError:
        logger.warning("github.login.failed", exc_info=True)
        return _login_error("github_failed")

    # L4: Rotate session after successful auth to prevent session fixation.
    session.clear()
    session.permanent = True
    session["user_id"] = uid
    return redirect("/")

_ORDER_BY_RE = re.compile(r"^[a-zA-Z_][a-zA-Z0-9_]*(\s+(ASC|DESC))?$", re.IGNORECASE)


@admin_bp.get("/api/admin/db/<table>")
def db_table(table: str):
    """
    Dump rows from any table.  Query params:
      order_by  — column name with optional ASC/DESC (e.g. "id DESC")
      limit     — integer row limit
      offset    — integer row offset

    Note: freeform WHERE is intentionally not supported to prevent SQL injection.
    Use the purpose-built endpoints (e.g. /api/admin/users) for filtered views.
    """
    ok, err = _require_admin_user()
    if err:
        return err
    conn = _db_conn()
    try:
        allowed = set(_list_tables(conn))
        if table not in allowed:
            return jsonify({"error": f"Unknown table: {table}"}), 404

        order_by = request.args.get("order_by", "").strip()
        limit    = request.args.get("limit", type=int)
        offset   = request.args.get("offset", type=int)

        # H1: Validate order_by to only allow a column name + optional ASC/DESC.
        if order_by and not _ORDER_BY_RE.match(order_by):
            return jsonify({"error": "order_by must be a column name with optional ASC/DESC"}), 400

        # For the films table, include a per-film rating count.
        # L5: For the users table, exclude the password_hash column.
        if table == "films":
            base = (
                "SELECT *, "
                "(SELECT COUNT(*) FROM ratings WHERE film_id = films.id) AS rating_count "
                "FROM films"
            )
        elif table == "users":
            base = "SELECT id, email, ia_username, github_username, is_admin, created_at FROM users"
        else:
            base = f"SELECT * FROM {table}"

        sql = base
        params: list = []
        if order_by:
            sql += f" ORDER BY {order_by}"
        if limit is not None:
            sql += " LIMIT ?"
            params.append(limit)
        if offset is not None:
            sql += " OFFSET ?"
            params.append(offset)

        rows = conn.execute(sql, params).fetchall()
        return jsonify([{k: r[k] for k in r.keys()} for r in rows])
    finally:
        conn.close()

# Tables in dependency order for restore (parents before children).
_RESTORE_ORDER = [
    "schema_migrations",
    "app_settings",
    "users",
    "criteria",
    "films",
    "ratings",
    "rating_scores",
]

BACKUP_FORMAT_VERSION = 1


@admin_bp.get("/api/admin/db/backup")
def db_backup():
    """Export the entire database as a versioned JSON file."""
    ok, err = _require_admin_user()
    if err:
        return err
    conn = _db_conn()
    try:
        # Resolve schema version from migrations table.
        try:
            row = conn.execute("SELECT MAX(version) AS v FROM schema_migrations").fetchone()
            schema_version = int(row["v"]) if row and row["v"] is not None else 0
        except Exception:
            schema_version = 0

        exported_at = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")

        tables = _list_tables(conn)
        tables_data = {}
        for t in tables:
            rows = conn.execute(f"SELECT * FROM {t}").fetchall()
            tables_data[t] = [{k: r[k] for k in r.keys()} for r in rows]

        backup = {
            "app": "ia_ratings",
            "format_version": BACKUP_FORMAT_VERSION,
            "schema_version": schema_version,
            "exported_at": exported_at,
            "tables": tables_data,
        }

        filename = f"ia_ratings_backup_{exported_at.replace(':', '-')}.json"
        return Response(
            json.dumps(backup, indent=2, ensure_ascii=False),
            mimetype="application/json",
            headers={"Content-Disposition": f'attachment; filename="{filename}"'},
        )
    finally:
        conn.close()


@admin_bp.post("/api/admin/db/restore")
def db_restore():
    """
    Restore the database from a backup JSON produced by /api/admin/db/backup.
    DESTRUCTIVE: all existing rows in every restored table are replaced.
    """
    ok, err = _require_admin_user()
    if err:
        return err

    backup = request.get_json(silent=True)
    if not backup:
        return jsonify({"error": "Request body must be JSON"}), 400
    if backup.get("app") != "ia_ratings":
        return jsonify({"error": "Invalid backup: unexpected app identifier"}), 400
    if backup.get("format_version") != BACKUP_FORMAT_VERSION:
        return jsonify({"error": f"Unsupported format_version: {backup.get('format_version')}"}), 400

    tables_data = backup.get("tables")
    if not isinstance(tables_data, dict):
        return jsonify({"error": "Invalid backup: 'tables' must be an object"}), 400

    conn = _db_conn()
    try:
        conn.execute("PRAGMA foreign_keys = OFF")
        restored = {}
        try:
            with conn:  # single atomic transaction — rolls back on any exception
                for table in _RESTORE_ORDER:
                    rows = tables_data.get(table)
                    if rows is None:
                        continue  # table not in backup — leave as-is
                    conn.execute(f"DELETE FROM {table}")
                    if not rows:
                        restored[table] = 0
                        continue
                    # M2: Validate column names against the real schema before use.
                    actual_cols = {
                        r["name"]
                        for r in conn.execute(f"PRAGMA table_info({table})").fetchall()
                    }
                    given_cols = set(rows[0].keys())
                    unknown = given_cols - actual_cols
                    if unknown:
                        raise ValueError(
                            f"Backup contains unknown columns for table '{table}': {sorted(unknown)}"
                        )
                    cols = [c for c in rows[0].keys() if c in actual_cols]
                    placeholders = ", ".join("?" * len(cols))
                    col_names = ", ".join(f'"{c}"' for c in cols)
                    for r in rows:
                        conn.execute(
                            f"INSERT INTO {table} ({col_names}) VALUES ({placeholders})",
                            [r.get(c) for c in cols],
                        )
                    # Keep SQLite AUTOINCREMENT sequences consistent.
                    ids = [r["id"] for r in rows if r.get("id") is not None]
                    if ids:
                        conn.execute(
                            "INSERT OR REPLACE INTO sqlite_sequence (name, seq) VALUES (?, ?)",
                            (table, max(ids)),
                        )
                    restored[table] = len(rows)
        except ValueError as exc:
            return jsonify({"error": str(exc)}), 400
        finally:
            conn.execute("PRAGMA foreign_keys = ON")

        return jsonify({
            "ok": True,
            "exported_at": backup.get("exported_at"),
            "schema_version": backup.get("schema_version"),
            "restored": restored,
        })
    finally:
        conn.close()

        "admin.collection.changed user_id=%s collection=%s", session.get("user_id"), current_app.repos["settings"].get_collection()
    )
    return jsonify({"ok": True, **_collection_payload(), "film_count": current_app.repos["films"].count()})

def _parse_import_request(data: dict):
    """Return (headers, rows, mapping) from an import request body, or raise ValueError."""
    headers, rows = import_service.parse_csv(data.get("csv_text") or "")
    mapping = import_service.validate_mapping(data.get("mapping"), len(headers))
    return headers, rows, mapping


@admin_bp.post("/api/admin/import/preview")
def import_preview():
    """Read a CSV and suggest a column mapping. Saves nothing."""
    ok, err = _require_admin_user()
    if err:
        return err
    data = request.get_json(silent=True) or {}
    try:
        headers, rows = import_service.parse_csv(data.get("csv_text") or "")
    except ValueError as exc:
        return jsonify({"error": str(exc)}), 400
    return jsonify({
        "headers": headers,
        "row_count": len(rows),
        "sample_rows": [[c[:200] for c in cells] for _, cells in rows[:5]],
        "suggested_mapping": import_service.suggest_mapping(headers, rows),
        "collection": current_app.repos["settings"].get_collection(),
    })


@admin_bp.post("/api/admin/import")
def import_films():
    """Import films from a CSV using a column mapping; `dry_run` only reports what would happen."""
    ok, err = _require_admin_user()
    if err:
        return err
    data = request.get_json(silent=True) or {}
    dry_run = bool(data.get("dry_run"))
    on_existing = data.get("on_existing")
    if not dry_run:
        if on_existing not in ("skip", "update"):
            return jsonify({"error": 'on_existing must be "skip" or "update"'}), 400
        if current_app.services["sync"].is_running():
            return jsonify({"error": "Wait for the running sync / title lookup to finish first"}), 409
    try:
        headers, rows, mapping = _parse_import_request(data)
    except ValueError as exc:
        return jsonify({"error": str(exc)}), 400

    importer = current_app.services["import"]
    items = importer.build_plan(headers, rows, mapping)
    summary = importer.summarize(items)
    skipped = importer.skipped_rows(items)
    if dry_run:
        return jsonify({
            "ok": True, "dry_run": True, "summary": summary, "skipped": skipped,
            "samples": importer.samples(items), "collection": current_app.repos["settings"].get_collection(),
        })
    if summary["new"] + summary["existing"] == 0:
        return jsonify({"error": "No rows with an archive.org link to import", "summary": summary, "skipped": skipped}), 400
    result = importer.run(items, on_existing, bool(data.get("lookup_titles")))
    current_app.logger.info("admin.import user_id=%s result=%s", session.get("user_id"), result)
    return jsonify({"ok": True, "result": result, "summary": summary, "skipped": skipped})

    )
